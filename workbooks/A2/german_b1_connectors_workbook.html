📜 The 3 Golden Rules of Sentence Structure

Category Position Sentence Formula Example
1. Subordinating Verb to End [Clause 1], CONN + Subj + ... + VERB. ..., weil ich Deutsch lerne.
2. Coordinating (ADUSO) Position 0 [Clause 1], CONN + Subj + VERB + ... ..., denn ich lerne Deutsch.
3. Adverbial Position 1 [Clause 1]. CONN + VERB + Subj + ... ... deshalb lerne ich Deutsch.

1. Subordinating (Verb END 🔻)

  • weil (because) / da (since)
  • damit (so that - diff subjects)
  • um...zu (in order to - same subject)
  • wenn (if/when) / als (when past)
  • bevor (before) / nachdem (after)
  • während (while) / seitdem (since)
  • obwohl (although)
  • dass (that) / ob (whether)

2. Coordinating (Pos 0 ➡️)

Mnemonic: ADUSO

  • Aber (but)
  • Denn (because/for)
  • Und (and)
  • Sondern (but rather)
  • Oder (or)

3. Adverbial (Pos 1 🔀)

  • deshalb / darum / deswegen (therefore)
  • trotzdem (nevertheless)
  • dann / danach (then/after that)
  • außerdem (besides/furthermore)
  • sonst (otherwise)

4. Two-Part 🔗

  • sowohl ... als auch (both... and)
  • weder ... noch (neither... nor)
  • nicht nur ... sondern auch (not only...)
  • entweder ... oder (either... or)
  • zwar ... aber (indeed... but)
