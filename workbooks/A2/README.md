# A2 German Workbooks - Interactive Practice

## Overview
Complete set of interactive A2-level German grammar workbooks with 100 exercises each. Features modern UI with Tailwind CSS, progress tracking, and immediate feedback.

## Workbooks

### ✅ Workbook 1: Connectors (Konjunktionen)
- **File**: `workbook-1.html`
- **Topics**: Coordinating, subordinating, and adverbial conjunctions
- **Exercises**: 100 (und, aber, weil, dass, deshalb, etc.)

### ✅ Workbook 2: Modal Verbs (Modalverben)
- **File**: `workbook-2-modal-verbs.html`
- **Topics**: können, müssen, wollen, dürfen, sollen, mögen/möchte
- **Sections**:
  1. Modal Verb Selection (25 exercises)
  2. Conjugation Practice (25 exercises)
  3. Complete Sentences (20 exercises)
  4. Sentence Building (15 exercises)
  5. Translation (15 exercises)

### ✅ Workbook 3: Reflexive Verbs (Reflexive Verben)
- **File**: `workbook-3-reflexive-verbs.html`
- **Topics**: Reflexive pronouns (accusative & dative), common reflexive verbs
- **Sections**:
  1. Accusative Pronouns (25 exercises)
  2. Conjugation (25 exercises)
  3. Dative Pronouns (20 exercises)
  4. Questions (15 exercises)
  5. Translation (15 exercises)

## Features

✨ **Interactive UI**
- Modern design with Tailwind CSS
- Mobile-responsive layout
- Smooth animations and transitions

📊 **Progress Tracking**
- Automatic save to browser localStorage
- Real-time progress statistics
- Accuracy percentage tracking
- Per-section progress badges

🎯 **Exercise Types**
- **Fill-in-the-blank**: Multiple choice with immediate feedback
- **Sentence building**: Free-form writing with model answers
- **Translation**: English to German practice
- **Hints**: Available for every exercise

🎨 **Color Coding**
- ✓ Green: Correct answers
- ✗ Red: Incorrect answers (review needed)
- Gray: Unsolved exercises
- Each workbook has its own theme color

## How to Use

1. **Open any workbook** in a web browser (works offline after first load)
2. **Navigate sections** using the sidebar menu
3. **Complete exercises** by selecting answers or typing responses
4. **Track progress** in the header and sidebar badges
5. **Review mistakes** - incorrect answers are marked for review
6. **Reset progress** anytime using the Reset button

## Technical Details

- **Framework**: Vanilla JavaScript + Tailwind CSS
- **Storage**: Browser localStorage (no server required)
- **Compatibility**: Modern browsers (Chrome, Firefox, Safari, Edge)
- **Mobile**: Fully responsive, touch-optimized
- **Offline**: Works without internet connection
