Cheatsheet: Passiv (Vorgangspassiv)

1. Formation: werden + Partizip II

The conjugated form of werden takes the normal verb position (position 2 in a main clause); the Partizip II always goes to the very end of the clause.

PersonPräsensPräteritum
ichwerdewurde
duwirstwurdest
er/sie/eswirdwurde
wirwerdenwurden
ihrwerdetwurdet
sie/Siewerdenwurden

Example: Die Suppe wird gekocht. (Präsens) — Die Suppe wurde gekocht. (Präteritum)

2. Aktiv → Passiv: was verändert sich?

AktivPassiv
Der Koch kocht die Suppe.
Subjekt (Nom.): der Koch · Akkusativobjekt: die Suppe		Die Suppe wird von dem Koch gekocht.
Akkusativobjekt → neues Subjekt (Nom.)

Regel: the Akkusativobjekt of the active sentence becomes the Nominativ subject of the passive sentence. The original subject becomes optional. Only transitive verbs (verbs with an Akkusativobjekt) can form a Passiv.

3. von + Dativ oder durch + Akkusativ?

von + Dativdurch + Akkusativ
A person or agent performs the actionAn impersonal cause, means, or instrument
von dem Koch, von der Firma, von den Kinderndurch den Sturm, durch das Feuer, durch eine neue Methode

4. Passiv ohne Agens

Very often, no agent is mentioned at all — this is completely normal and grammatical, especially when the "doer" is unknown, obvious, or irrelevant.

BeispielAnmerkung
Hier wird nicht geraucht.no logical subject at all (impersonal)
Der Vertrag wurde unterschrieben.agent omitted, though known from context
Section A — Aktiv → Passiv, Präsens (1–6)
Rewrite each active sentence in the Vorgangspassiv, Präsens. Decide whether an agent needs "von" or "durch" — or no agent at all.
1. Der Lehrer erklärt die Regel.
LösungDie Regel wird von dem Lehrer erklärt. Akkusativobjekt "die Regel" → neues Subjekt; der Lehrer = Person → von + Dativ
2. Die Firma stellt viele Mitarbeiter ein.
LösungViele Mitarbeiter werden von der Firma eingestellt. separable verb einstellen → Partizip II eingestellt goes to the very end; Subjekt ist Plural → werden
3. Die Kinder essen den Kuchen.
LösungDer Kuchen wird von den Kindern gegessen. essen → gegessen (strong verb)
4. Man baut hier ein neues Krankenhaus.
LösungHier wird ein neues Krankenhaus gebaut. "man" as active subject is simply dropped — it never reappears as "von man"
5. Der Sturm zerstört das Dach.
LösungDas Dach wird durch den Sturm zerstört. der Sturm = impersonal cause, not a person → durch + Akkusativ
6. Die Studenten schreiben viele E-Mails.
LösungViele E-Mails werden von den Studenten geschrieben. schreiben → geschrieben (strong verb)
Section B — Aktiv → Passiv, Präteritum (7–12)
Rewrite each active sentence in the Vorgangspassiv, Präteritum.
7. Der Architekt entwarf das Gebäude.
LösungDas Gebäude wurde von dem Architekten entworfen. entwerfen → entworfen; "Architekt" is a weak noun: dem Architekten (Dativ)
8. Ein Blitz beschädigte das Auto.
LösungDas Auto wurde durch einen Blitz beschädigt. ein Blitz = impersonal cause → durch + Akkusativ
9. Die Regierung erhöhte die Steuern.
LösungDie Steuern wurden von der Regierung erhöht. Subjekt "die Steuern" ist Plural → wurden
10. Man renovierte die alte Schule letztes Jahr.
LösungDie alte Schule wurde letztes Jahr renoviert. "man" is dropped entirely; renovieren has no ge- (-ieren verb)
11. Die Feuerwehr rettete die Familie.
LösungDie Familie wurde von der Feuerwehr gerettet. die Feuerwehr = agent (organization acting like a person) → von + Dativ
12. Ein Erdbeben zerstörte die Stadt.
LösungDie Stadt wurde durch ein Erdbeben zerstört. ein Erdbeben = impersonal cause → durch + Akkusativ

Section F — Cloze: Brot backen (31–36)
Fill each numbered gap with the Partizip II of the verb given in brackets. "werden" is already correctly conjugated for you in the text — this is a bakery's process, described in the Vorgangspassiv, Präsens.

Die Herstellung von Brot ist ein faszinierender Prozess. Zuerst werden Mehl, Wasser, Hefe und Salz zu einem Teig ① (mischen). Der Teig wird zehn Minuten lang von Hand ② (kneten). Danach werden kleine Brote aus dem Teig ③ (formen). Die Brote werden bei 220 Grad im Ofen ④ (backen). Nach dem Backen wird das frische Brot in Scheiben ⑤ (schneiden). Zum Schluss wird das Brot direkt in der Bäckerei ⑥ (verkaufen).
