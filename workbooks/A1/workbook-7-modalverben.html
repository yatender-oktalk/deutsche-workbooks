Cheatsheet: Modalverben

ihrkönntmüsstwolltdürftmöchtet
sie/Siekönnenmüssenwollendürfenmöchten

ich and er/sie/es are the same and have no ending. The vowel changes in the singular (können → ich kann), except möchten.

Satzklammer

Modal verb in position 2, the other verb as an infinitive at the very end: „Ich muss heute lange arbeiten."   „Kannst du mir helfen?"

Meaning

können = be able to / possible · müssen = have to · wollen = want to · möchten = would like (polite) · dürfen = be allowed to · nicht dürfen = must not.

Section C — Satzklammer: Infinitiv ans Ende (14–19)
Build the sentence. Modal in position 2, infinitive at the end.
14.ich / können / heute / nicht / kommen
LösungIch kann heute nicht kommen.
15.du / müssen / das Formular / unterschreiben
LösungDu musst das Formular unterschreiben.
16.wir / wollen / am Wochenende / eine Radtour / machen
LösungWir wollen am Wochenende eine Radtour machen.
17.können / du / mir / helfen / ? (Frage)
LösungKannst du mir helfen?
18.Setze „Heute" an den Anfang: „Ich muss lange arbeiten."
LösungHeute muss ich lange arbeiten. „Heute" auf Position 1 → Verb bleibt auf Position 2, Subjekt danach
19.ich / möchten / ein Zimmer / für zwei Nächte / reservieren
LösungIch möchte ein Zimmer für zwei Nächte reservieren.
