Cheatsheet: Akkusativ

The accusative is the direct object (Wen? Was?). Good news: only the masculine article changes. die, das and plural stay exactly the same.

maskulinfemininneutrumPlural
Nominativder / ein / meindie / eine / meinedas / ein / meindie / meine
Akkusativden / einen / meinendie / eine / meinedas / ein / meindie / meine

Accusative pronouns

ichduersieeswirihrsie/Sie
michdichihnsieesunseuchsie / Sie

Prepositions always with the accusative

durch, für, gegen, ohne, um. Contractions: durch das = durchs, für das = fürs, um das = ums.

Common accusative verbs: haben, brauchen, kaufen, essen, trinken, sehen, lesen, nehmen, suchen, finden, besuchen, mögen — and es gibt + Akkusativ.
