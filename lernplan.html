PLAN — B1 · B2

Lernplan — Tag für Tag

Kalenderplan für die telc-Prüfung: B1 in 42 Tagen, B2 in 48 Tagen · jeder Tag = ein Schwerpunkt, ca. 2 Stunden · jede Aufgabe führt zu einer Seite in diesem Repo · Häkchen bleiben auf diesem Gerät gespeichert

How to use this page: pick B1 or B2, set the start date (or press the exam button to end the plan 3 days before your exam date from the profile), then work one day at a time and tick it off. The plan rotates through grammar, reading, language modules, listening, writing and speaking, moves from untimed to timed, and ends with model-test days. It is an original plan built on this repo's pages — it is not a copy of any course. Time estimates are rough. Exact telc task formats can shift between test versions — check the current telc Modellsatz.

Was dieser Plan nicht abdeckt

Für B2 gibt es hier keine Lückenbrief-Seite wie schriftlicher-ausdruck-luecken (nur B1), und keine vollständigen Modelltests im Repo — an den Modelltest-Tagen die offiziellen telc-Modellsätze verwenden und die Repo-Seiten als Ergänzung nehmen. Bewertet wird selbst: es gibt keinen automatischen Prüfer für Schreiben und Sprechen, also Modellantworten und Checklisten ehrlich nutzen.
